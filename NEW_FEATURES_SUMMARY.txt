1️⃣ DELETE ALL PAIRS - Bulk Deletion Feature
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

✅ What it does:
Delete ALL keyword/URL pairs and their complete history with one click.

✅ Key Features:
- Red "Supprimer tout" button in main interface
- Double confirmation for safety
- Shows exact count before deletion
- Deletes pairs AND all history entries
- Success notification with deleted count
- Button disabled when empty or loading

✅ Safety:
1st confirmation: "Êtes-vous sûr de vouloir supprimer TOUS les X couples ?"
2nd confirmation: "Dernière confirmation : Supprimer tous les couples et leur historique ?"

✅ Use Cases:
- Reset project completely
- Clear test data
- Start fresh tracking
- Seasonal cleanup

API: DELETE /api/v1/pairs/delete-all
File: app/api/v1/pairs/delete-all/route.ts

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
2️⃣ DOMAIN TRACKING - Track Entire Domains
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

✅ What it does:
Track keyword positions for ANY page from a domain, not just specific URLs.

✅ Key Features:
- Enter just "outscale.com" instead of full URL
- System finds best position across all domain pages
- Visual indicator: 🌐 Domaine badge
- Works in manual entry and CSV import
- Automatic detection (domain vs URL)
- Tooltip explanations

✅ Examples:

Input Format → Behavior:
- "outscale.com" → Tracks any page from outscale.com, returns best position
- "https://outscale.com/page" → Tracks this specific page only

Real Example:
Keyword: "cloud"
Results:
  Position 1: https://fr.outscale.com/
  Position 5: https://blog.outscale.com/cloud
  Position 10: https://outscale.com/products

→ If tracking "outscale.com": Returns position 1 ✅
→ If tracking "https://blog.outscale.com/cloud": Returns position 5 ✅

✅ Visual Indicators:
- Domain entries: 🌐 Domaine outscale.com (blue badge)
- URL entries: https://outscale.com/page (normal link)
- Input placeholder: "URL ou domaine (ex: outscale.com)"
- Edit tooltip: "Entrez une URL complète ou juste un domaine"

✅ Use Cases:
- Brand monitoring (any page from your domain)
- Don't care about specific landing page
- Automatic best position detection
- Competitor domain tracking
- Multi-page SEO campaigns

✅ CSV Import Support:
```csv
Mot-clé,URL
cloud,outscale.com          ← Domain tracking
iaas,https://fr.outscale.com/page  ← URL tracking
```

Delete All:
- API: DELETE /api/v1/pairs/delete-all
- Queries all pairs via DynamoDB GSI
- Deletes pair + all history entries
- Returns: { deleted: count, errors: [...] }
- Frontend: Double confirm → API call → Clear UI

Domain Tracking:
- Detection: No http://, no path → domain
- Storage: Stores domain as-is (e.g., "outscale.com")
- Matching: SerpAPI finds best domain position
- Display: Badge + link for domains, normal link for URLs

Integration:
- Works with existing CSV import
- Works with manual entry
- Works with edit function
- Works with all tracking APIs
- Works with export (shows domain in data)
