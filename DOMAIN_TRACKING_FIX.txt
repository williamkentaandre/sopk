✅ PROBLÈME 1: Le calcul de position ne fonctionnait pas pour les domaines seuls
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Symptôme:
- Quand l'utilisateur entrait "example.com" (sans URL)
- Le système ne calculait pas la position correctement
- Seules les URLs complètes fonctionnaient

Cause:
La logique de matching ne différenciait pas entre:
- Domaine seul: "example.com" → Doit chercher toutes les pages de ce domaine
- URL complète: "https://example.com/page" → Doit chercher cette page exacte

Solution:
Amélioration de la fonction matchUrlInResults() dans lib/serpapi.ts:

1. Détection du type d'entrée:
   ```typescript
   const isDomainOnly = !targetUrl.startsWith('http://') && 
                        !targetUrl.startsWith('https://') && 
                        !targetUrl.includes('/');
   ```

2. Stratégie de matching adaptée:
   - Si DOMAINE SEUL → Matching de domaine uniquement (meilleure position)
   - Si URL COMPLÈTE → Exact match d'abord, puis domaine en fallback

3. Logs améliorés:
   - Affiche "Is Domain Only: true/false"
   - Permet de débugger facilement le comportement

🔍 DÉTAILS TECHNIQUES: Comment fonctionne le matching maintenant
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

CAS 1: Domaine seul (example.com)
1. isDomainOnly = true
2. Pour chaque résultat Google:
   - Extrait le domaine du résultat
   - Compare avec le domaine cible
   - Garde la meilleure position (plus petite)
3. Retourne la position la plus basse trouvée

Exemple:
Input: "example.com"
Résultats Google:
  Position 3: https://www.example.com/about
  Position 7: https://example.com/products
  Position 12: https://blog.example.com/article
→ Retourne position 3 ✅

CAS 2: URL complète (https://example.com/page)
1. isDomainOnly = false
2. Pour chaque résultat Google:
   - Essaie d'abord un match exact (URL complète normalisée)
   - Si trouvé → retourne immédiatement
   - Sinon, essaie le match de domaine
3. Retourne exact match OU meilleure position du domaine

Exemple:
Input: "https://example.com/products"
Résultats Google:
  Position 3: https://www.example.com/about
  Position 7: https://example.com/products  ← Match exact!
  Position 12: https://blog.example.com/article
→ Retourne position 7 (exact) ✅
