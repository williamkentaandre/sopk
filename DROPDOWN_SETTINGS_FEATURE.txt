Menu déroulant Langue:
```tsx
<select
  value={settings.hl}
  onChange={(e) => setSettings({ ...settings, hl: e.target.value })}
>
  <option value="fr">Français</option>
  <option value="en">Anglais (English)</option>
  <option value="es">Espagnol (Español)</option>
  ...
</select>
```

Menu déroulant Emplacement:
```tsx
<select
  value={settings.gl}
  onChange={(e) => setSettings({ ...settings, gl: e.target.value })}
>
  <option value="fr">France</option>
  <option value="be">Belgique</option>
  <option value="ch">Suisse</option>
  ...
</select>
```

Style unifié pour input et select:
```css
.form-group input,
.form-group select {
  width: 100%;
  padding: 0.5rem;
  border: 1px solid #ddd;
  border-radius: 4px;
  font-size: 1rem;
  background: white;
}

.form-group input:focus,
.form-group select:focus {
  outline: none;
  border-color: #1a73e8;
}

.form-group select {
  cursor: pointer;
}
```

Caractéristiques:
- Même style que les inputs (cohérence visuelle)
- Background blanc (pour compatibilité navigateurs)
- Cursor pointer pour indiquer l'interactivité
- Focus bleu (#1a73e8) comme les autres éléments

Workflow:
1. Utilisateur ouvre la page
2. Voit "Français" et "France" par défaut
3. Clique sur un menu déroulant
4. Liste des options s'affiche
5. Sélectionne une option
6. Valeur se met à jour immédiatement
7. Clique "Sauvegarder" pour persister

Valeur par défaut:
- Langue (hl): "fr" (Français)
- Emplacement (gl): "fr" (France)

Si valeur stockée non reconnue:
- Affiche quand même la valeur
- Utilisateur peut la changer via le menu

5. Tous les futurs trackings utiliseront hl=es, gl=es

Scénario: Tracking multi-pays

1. Tracking France: hl=fr, gl=fr
2. Tracking Belgique francophone: hl=fr, gl=be
3. Tracking Canada francophone: hl=fr, gl=ca
4. Tracking Suisse francophone: hl=fr, gl=ch

Tous avec la même langue, différents emplacements.
