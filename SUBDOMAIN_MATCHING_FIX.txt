❌ ANCIEN COMPORTEMENT (lib/url-utils.ts)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

extractDomain() retournait le hostname complet:

```typescript
let hostname = urlObj.hostname.toLowerCase();

  hostname = hostname.substring(4);
}
return hostname;  // ❌ Retourne TOUT le hostname
```

- "https://blog.outscale.com" → "blog.outscale.com"  ❌
- "https://www.outscale.com" → "outscale.com"  ✅ (www. retiré)

Résultat:
- "outscale.com" ≠ "fr.outscale.com" ❌

✅ NOUVEAU COMPORTEMENT (CORRIGÉ)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

extractDomain() extrait maintenant le DOMAINE RACINE (sans sous-domaine):

```typescript
let hostname = urlObj.hostname.toLowerCase();

// Remove www. prefix
if (hostname.startsWith('www.')) {
  hostname = hostname.substring(4);
}

// Extract root domain (remove subdomains)
const parts = hostname.split('.');

if (parts.length <= 2) {
  // Already a root domain
  return hostname;
}

// For subdomains, take last 2 parts
const rootDomain = parts.slice(-2).join('.');
return rootDomain;  // ✅ Retourne le domaine RACINE
```

Exemples:
- "https://fr.outscale.com" → "outscale.com"  ✅
- "https://blog.outscale.com" → "outscale.com"  ✅
- "https://www.outscale.com" → "outscale.com"  ✅
- "https://api.v2.outscale.com" → "outscale.com"  ✅
- "outscale.com" → "outscale.com"  ✅
- "google.com" → "google.com"  ✅

Résultat:
- "outscale.com" = "outscale.com" ✅
- MATCH TROUVÉ !

CAS 3: TLD avec plusieurs parties (edge case)
-----------------------------------------------

Note: Cette implémentation simple ne gère pas les TLDs composés
comme .co.uk, .com.au, etc.

"example.co.uk" → "co.uk"  ⚠️ (Limitation connue)

Pour la plupart des cas (.com, .fr, .org, etc.), ça fonctionne parfaitement.

Problème racine:
Les sous-domaines (fr., blog., api., etc.) n'étaient pas reconnus comme
faisant partie du domaine principal.

Solution:
Extraire le domaine RACINE en prenant les 2 dernières parties du hostname.

Résultat:
Le domain tracking fonctionne maintenant correctement, même quand Google
retourne des sous-domaines dans les résultats.
